# リスティング広告 運用戦略（DCかいご相談ダイヤル）

介護施設・高齢者住宅の入居相談を、検索連動型広告（Google 広告中心）で獲得するための戦略。
本システムの実装（悩み別LP8本・gclid取得・チャネル別KPI・広告レポート）を前提に、
そのまま運用に落とせる形でまとめる。

> 表記の `【要設定】` は事業側で数値・方針を決める箇所。

---

## 1. 目的とKPI

- **最終ゴール**: 入居（成約）数の最大化と、獲得単価（CPA）の最適化。
- **広告の直接CV**: 無料相談（フォーム送信／電話発信／LINE相談）。
- **真のKPI**: 相談 → 見学 → 入居 のファネル。広告は「相談CPA」で測り、
  最終的には「入居CPA / ROAS」で評価する（後述のオフラインCV連携で接続）。

| 指標 | 定義 | 目安（要実数で更新） |
|---|---|---|
| 相談CPA | 広告費 ÷ 相談数 | 【要設定】 |
| 相談CVR | 相談数 ÷ クリック数 | 3〜8%（LP/キーワード次第） |
| 相談→見学率 | 見学数 ÷ 相談数 | CRMの実績から算出 |
| 見学→入居率 | 入居数 ÷ 見学数 | CRMの実績から算出 |
| 入居CPA | 広告費 ÷ 入居数 | 相談CPA ÷（相談→入居率） |

> CRM のチャネル別ダッシュボード（WEB集客の相談/見学/入居/成約率）と
> 広告レポート（cost/impressions/clicks/conversions/tours/move_ins）で実数を埋める。

## 2. 媒体選定

- **主軸: Google 広告（検索）**。介護施設探しは顕在ニーズが検索に集中するため最優先。
- **補完: Yahoo!広告（検索）**。シニア世代の家族層はYahoo利用率も高い。Google安定後に横展開。
- P-MAX・ディスプレイは初期は使わない（指名・顕在の検索でCPAを固めてから検討）。
- **指名/競合名は最小限**。自社名の防衛出稿のみ小予算で。

---

## 3. ターゲティング

- **地域**: 大阪府（特に大阪市・北摂・東大阪など対応エリア）。【要設定：対応市区町村】
  - 「所在地・関心のある地域」を**所在地のみ**に絞る（旅行者・遠方の情報収集を除外）。
  - ただし「遠方に住む家族が大阪の親の施設を探す」需要があるため、
    主要都市圏（東京等）は別キャンペーンで限定テスト可。
- **デバイス**: モバイル重視（家族がスマホで検索→電話が多い）。
- **広告スケジュール**: 受付時間帯を厚めに（電話CVを取りこぼさない）。
  受付時間外は入札を下げる or フォーム/LINE訴求に寄せる。営業時間は `site_settings.business_hours` と整合。
- **オーディエンス**: 「シニア向け」「介護」関心層を**観察（モニタリング）**で付与し、
  データが溜まったら入札調整。年齢の絞り込みは取りこぼし注意（家族は40〜60代）。

## 4. アカウント構成（キャンペーン → 広告グループ）

**悩み別LP（`/soudan/[slug]`）と1:1で対応させる**のが本戦略の核。検索意図とLPが一致し、
品質スコア・CVRが上がる。

| キャンペーン（テーマ） | 対応LP | 主な検索意図 |
|---|---|---|
| 認知症 | `/soudan/dementia` | 認知症 老人ホーム / 徘徊 施設 |
| 生活保護 | `/soudan/welfare` | 生活保護 入れる 老人ホーム |
| 身寄りなし・保証人 | `/soudan/no-family` | 身寄りなし 施設 / 保証人なし 入居 |
| 退院後・急ぎ | `/soudan/post-discharge` | 退院 施設 すぐ / 退院後 住まい |
| 医療対応 | `/soudan/medical` | たん吸引 施設 / 胃ろう 老人ホーム |
| 費用を抑えたい | `/soudan/low-cost` | 安い 老人ホーム / 年金 入れる 施設 |
| 要介護度が高い | `/soudan/high-care` | 要介護5 施設 / 寝たきり 受け入れ |
| 精神疾患 | `/soudan/mental` | 精神疾患 入れる 施設 |
| 一般・横断 | `/`（トップ） | 老人ホーム 大阪 / 介護施設 紹介 |

- 構成は **キャンペーン=テーマ／予算管理単位**、**広告グループ=キーワードの粒度**。
- 緊急度の高い「退院後」「医療対応」はCVが濃いので**優先的に予算配分**。

## 5. キーワード設計

### マッチタイプ方針
- 立ち上げは**フレーズ一致**中心＋一部**完全一致**。インテントマッチ/部分一致は
  除外キーワードを整備してから限定的に。
- 検索語句レポートを**週次で精査**し、良い語句は完全一致へ昇格、無駄はその場で除外。

### テーマ別キーワード例（地域語との掛け合わせ）
- 共通地域語: `大阪` `大阪市` `[区名]` `[沿線/駅]`
- 認知症: `認知症 老人ホーム` `認知症 受け入れ 施設` `徘徊 施設 入居`
- 生活保護: `生活保護 老人ホーム` `生活保護 入れる 施設` `生活保護 高齢者住宅`
- 身寄りなし: `身寄りなし 施設` `保証人なし 老人ホーム` `おひとりさま 施設 入居`
- 退院後: `退院後 施設` `退院 すぐ 老人ホーム` `病院 退院 住まい 探す`
- 医療対応: `たん吸引 施設` `胃ろう 老人ホーム` `インスリン 施設 入居` `看取り 施設`
- 費用: `老人ホーム 安い 大阪` `年金 で 入れる 老人ホーム` `特養 入れない 費用`
- 高介護度: `要介護5 施設` `寝たきり 受け入れ 施設`
- 一般: `老人ホーム 紹介 無料` `介護施設 探し 相談` `サ高住 大阪`

### 除外キーワード（必須）
求職・学習・無関係意図を遮断してCPA悪化を防ぐ。
```
求人 採用 バイト パート 正社員 給料 年収 転職 ハローワーク
資格 初任者研修 実務者研修 介護福祉士 ケアマネ 試験 通信講座 スクール
口コミ 評判 ランキング（※情報収集層。CVR低ければ除外/別ADグループ）
中古 物件 不動産 賃貸（高齢者向け以外）
補助金 助成金 制度（行政情報収集）
無料ゲーム 画像 イラスト
```
> 「特養」「特別養護老人ホーム」は費用感が合わず混在しやすい。意図を見て調整。

## 6. 広告文（レスポンシブ検索広告／例）

各広告グループでLPの訴求と一致させる。見出しは**地域×悩み×無料×スピード**を軸に。

**例：退院後キャンペーン**
- 見出し: `退院後の施設探し｜大阪` / `退院日に間に合う住まい探し` / `相談・紹介はすべて無料` /
  `医療対応の施設もご紹介` / `専門スタッフが即日対応` / `お電話1本で相談OK`
- 説明文: `退院日が迫っていても大丈夫。条件に合う施設を無料でご提案し、見学・入居まで調整します。` /
  `認知症・医療対応・生活保護のご相談も可能。まずはお気軽にお電話・LINEで。`

**例：生活保護キャンペーン**
- 見出し: `生活保護でも入れる施設｜大阪` / `予算内の住まいをご提案` / `相談無料・強引な勧誘なし`
- 説明文: `生活保護受給中の方の入居相談に対応。受け入れ可能な施設を無料でお探しします。`

**広告アセット（旧拡張）**
- **電話番号アセット**（受付時間設定。モバイルで通話CVを直接獲得）
- サイトリンク: `費用の目安` `よくある質問` `運営者情報` `空室・施設情報`
- コールアウト: `相談無料` `強引な勧誘なし` `専門スタッフ対応` `大阪エリア対応`
- 構造化スニペット: 対応可能な状況（認知症/生活保護/医療対応/身寄りなし）

> 表現はコンプライアンス（§11）に従い、誇大・断定（「必ず」「最安」等）を避ける。

## 7. ランディングページ戦略

- 検索キャンペーン → 対応する `/soudan/[slug]` LP へ誘導（既に実装済み・SSGで高速）。
- LPは**ファーストビューに3CTA**（電話／LINE／フォーム）と信頼要素（無料・勧誘なし・専門対応）を配置済み。
- フォームは**段階開示＋電話フォールバック**で離脱を抑制済み。
- 改善余地:
  - キャンペーン別に**見出しコピーをLP側と一致**させる（メッセージマッチ）。
  - 「退院後」「医療」など緊急度の高いLPは**電話CTAを最上部で強調**。
  - 計測タグはSSGページのため**環境変数で解決**（`NEXT_PUBLIC_GA_ID` / `GTM_ID` / `GOOGLE_ADS_ID`）。
    本番は環境変数に必ず設定（DB設定はSSGに反映されないため）。

## 8. 入札・予算（決定: 月10万円・Google単体スタート）

月10万円（≒**日予算3,300円**）は全テーマに薄く広げると学習が進まない。
**濃い意図2テーマ＋一般＋指名に集中**し、勝ち筋を見つけてから広げる。

### 予算配分（月10万円の例）
| 枠 | 月額 | 対応LP/狙い |
|---|---|---|
| 濃い意図A（退院後 or 医療） | 40,000円 | `/soudan/post-discharge` or `/medical`。緊急度が高くCVが濃い |
| 濃い意図B（認知症） | 30,000円 | `/soudan/dementia`。検索ボリュームが大きい |
| 一般（横断） | 22,000円 | `老人ホーム 大阪` `介護施設 紹介 無料` → トップ |
| 指名・防衛 | 8,000円 | 自社名。低CPCで取りこぼし防止 |
| **合計** | **100,000円** | |

> まずは2テーマで開始し、CPAが見えたら3つ目（生活保護・費用など）へ。

### 入札
- **立ち上げ期（CVが月30件たまるまで）**: 「クリック数最大化」＋**上限CPC**、または手動CPC。
  まずデータを貯める。月10万円規模だと30CV到達に1〜1.5か月かかる想定。
- **安定後**: 「コンバージョン数最大化」→「目標CPA（tCPA）」へ移行。
- **Yahoo!・P-MAX・ディスプレイ・リマケは当面オフ**（Google検索でCPAを固めてから）。

### 試算（前提を置いた概算・実数で更新）
- 介護系の想定CPC ≒ 150〜300円。仮に**200円**なら月**約500クリック**。
- 相談CVR **5%** なら月**約25件**の相談 → **相談CPA ≒ 4,000円**。
- 相談→見学→入居率はCRM実績で接続し、**入居CPA**で評価する（§9のオフラインCV連携）。
- 【要設定】目標相談CPA・目標入居CPA（上記試算をベンチに、初月実績で更新）。

## 9. 計測設計 ★本システムの強み

### コンバージョン定義（Google 広告 / GA4）
| CV | 取得方法 | 価値づけ |
|---|---|---|
| フォーム相談 | `submitContact` 完了（/thanks 到達 or イベント） | 主要CV |
| 電話相談 | 電話番号アセット通話＋LP内 `data-cv="phone"` クリック | 主要CV |
| LINE相談 | `data-cv="line"` クリック | 主要CV |

- LP内の各CTAには `data-cv="phone"` / `data-cv="line"` が付与済み。
  GTM でこれらのクリックをトリガにGoogle 広告/GA4のCVを発火させる。
- フォーム完了は `/thanks` 到達 or 送信成功イベントで計測。

### ★ オフラインCV連携（Smart Bidding の精度を一段上げる）
- **lead に `gclid` を保存済み**。CRMで相談→見学→入居と進むので、
  **実際の「見学」「入居」をGoogle 広告へオフラインコンバージョンとして戻す**ことで、
  「フォームを送った人」ではなく「本当に入居に至る人」を増やす方向に学習させられる。
- 実装案: `gclid` + コンバージョン名（見学/入居）+ 発生日時 + 価値 を
  **オフラインCVインポート（CSV or Google Ads API）**で定期送信。
  - まずは管理画面から **gclid付き成約のCSV出力**を用意し、手動アップロードから始めるのが低コスト。
- これにより tCPA/tROAS が「相談単価」ではなく「入居単価」基準で最適化できる。

## 10. 運用・改善サイクル

- **日次**: 予算消化・異常検知（CPA急騰、無関係な検索語句）。
- **週次**: 検索語句レポート精査 → 除外/昇格、広告文ABの差し替え、入札微調整。
- **月次**: CRMのチャネル別KPI（相談/見学/入居/成約率）と広告レポートを突合し、
  キャンペーン別の**入居CPA**で予算再配分。`ad_reports` に実績を記録。
- 失注理由（CRMの `lost_reason`）も確認し、CVだけでなく「質」を見る
  （例：費用ミスマッチが多い→「費用を抑えたい」訴求/キーワードを調整）。

## 11. コンプライアンス・審査の注意

- **医療・介護関連表現**: 効果・安全性の断定や誇大表現を避ける（薬機法/景表法）。
  「必ず入れる」「最安」「No.1（根拠なし）」等はNG。
- **生活保護・医療**: センシティブカテゴリ扱いになり得る。事実ベースの表現に留める
  （「生活保護受給中の方の入居相談に対応」など）。
- **個人情報**: LPにプライバシーポリシーへの導線あり（実装済み）。フォームはPIIを扱うため
  審査・運用で配慮。
- Google 広告ポリシー（個人向け融資・健康など）に抵触しない文言にする。広告審査落ち時は
  説明文・見出しを事実表現へ修正。

## 12. ローンチ手順（フェーズ）

1. **計測の土台**: 本番環境変数に GA4/GTM/Google 広告ID を設定 → 3CV（フォーム/電話/LINE）の発火確認。
2. **指名＋濃い2テーマで小さく開始**（退院後・医療 or 認知症）。除外キーワードを初日から整備。
3. **2〜4週でデータ蓄積** → 検索語句最適化、勝ち広告文の確定。
4. **tCPA移行＋テーマ横展開**（8LP全体へ）。
5. **オフラインCV連携を投入** → 入居基準での最適化。
6. **Yahoo!広告へ横展開**、必要に応じてリマーケティング。

## 13. 前提（決定事項と残課題）

**決定済み**
- 月間予算: **10万円**でスタート。
- 媒体: **Google検索のみ**で開始（Yahoo!・P-MAXは安定後に検討）。

**残課題（事業側で決める）**
- 目標CPA（相談／入居）— 初月実績で確定。試算は相談CPA≒4,000円（§8）。
- 対応エリア（市区町村）と、遠方家族向け配信の要否。
- 運用体制（内製／代理店）。
- オフラインCV連携（gclidエクスポート）を実装するか（推奨・次フェーズ）。
